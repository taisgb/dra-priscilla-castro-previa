# Dra. Priscilla Castro — prévia não oficial

Site estático HTML, CSS e JavaScript. Abra `index.html` ou publique os arquivos na raiz de um repositório GitHub Pages. Fotos originais tratadas de forma conservadora, em WebP com transparência. O CSS tenta carregar Allo via CDN; se não estiver disponível, utiliza fonte de sistema. Para garantir a fonte, consulte https://github.com/joshpuckett/allo e configure localmente o WOFF2 conforme a documentação oficial.

Antes da publicação final, confirmar endereço exato da Clínica Laço, mapa, formação em Nutrologia e autorização de uso de imagens. A prévia usa noindex/nofollow intencionalmente para não confundir com um site oficial; remover apenas após aprovação.
